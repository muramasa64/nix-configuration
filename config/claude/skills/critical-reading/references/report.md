# 官公庁・調査会社のレポート、統計資料のチェックリスト

## 出所
- 発行主体(官公庁、業界団体、調査会社、シンクタンク)と、その立場や政策上の意図を確認する。
- 調査の依頼主と資金提供元を確認する。業界団体の調査は業界に有利な結論になりやすい。
- 速報値か確報値か、改訂されていないかを確認する。

## 調査方法
- 調査方法(全数調査、標本調査、アンケート、ヒアリング)が書かれているか。
- 標本の抽出方法、回答数、回答率、調査期間が開示されているか。
- Webアンケートなど、回答者の偏りが生じやすい方法ではないか。
- 設問文と選択肢が公開されているか。誘導的な設問ではないか。

## 数値の扱い
- 定義(何を数えたか)が明記されているか。年度によって定義が変わっていないか。
- 割合の母数が明記されているか。全体に対する割合か、回答者に対する割合か。
- 時系列比較で、調査方法や対象の変更による断絶がないか。
- 市場規模の予測で、成長率の前提と算出方法が開示されているか。
- グラフの軸(原点、目盛り、期間の切り取り)で印象を操作していないか。

## 解釈
- データから直接言えることと、レポートの提言や解釈を区別する。
- 平均値だけでなく、ばらつきや中央値を見る必要がないか。
- 他の統計や調査と比べて、大きく外れた数値ではないか。外れている場合、理由の説明があるか。
